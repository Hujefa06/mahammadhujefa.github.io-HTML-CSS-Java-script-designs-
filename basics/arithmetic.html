JS-02 Math

Comprehensive Arithmetic Operations Engine

Demonstrates basic arithmetic calculation operators in JavaScript: Addition (+), Subtraction (-), Multiplication (*), Floating-point Division (/), Modulus Remainder (%), and Power Exponentiation (**).

🎯 Practical Laboratory Objective
Understand type coercion between string inputs (`input.value`) and numeric types (`parseFloat`), and learn to handle zero-division edge cases gracefully.

function calculate(a, b) {
  const sum        = a + b;
  const difference = a - b;
  const product    = a * b;
  const quotient   = b !== 0 ? (a / b) : "Division by Zero Error";
  const remainder  = b !== 0 ? (a % b) : "N/A";
  const power      = a ** b;

  return { sum, difference, product, quotient, remainder, power };
}
