JS-11 Math

Sum of Digits Calculation

Demonstrates extracting each base-10 digit using repeated modulus 10 operations and accumulating the sum: e.g. for input 4529, sum = 4 + 5 + 2 + 9 = 20.

🎯 Practical Laboratory Objective
Master while-loop termination conditions, accumulator variable patterns, and step-by-step arithmetic trace logging.

Working Demo

4 + 5 + 2 + 9 = 20 
function sumOfDigits(num) {
  let n = Math.abs(num);
  let sum = 0;

  while (n > 0) {
    sum += n % 10;
    n = Math.floor(n / 10);
  }

  return sum;
}
