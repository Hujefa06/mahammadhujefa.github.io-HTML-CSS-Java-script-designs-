JS-07 Series

Fibonacci Sequence Generator

Demonstrates the generation of the Fibonacci integer series where each successive number is the sum of the preceding two: F(0)=0, F(1)=1, F(n) = F(n-1) + F(n-2).

🎯 Practical Laboratory Objective
Understand iterative variable swapping algorithms and array accumulator patterns in JavaScript.
⚡ Live Fibonacci Sequence Generator
Working Demo
Generated Series Elements:
function getFibonacci(terms) {
  if (terms <= 0) return [];
  if (terms === 1) return [0];

  const series = [0, 1];
  for (let i = 2; i < terms; i++) {
    series.push(series[i - 1] + series[i - 2]);
  }
  return series;
}
