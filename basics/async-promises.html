JS-18 Async

Asynchronous JavaScript: Promises & Async/Await

Demonstrates non-blocking asynchronous event loop processing: Promise lifecycle states (Pending → Fulfilled / Rejected), error handling via try/catch, and sequential synchronous-style execution via `async` and `await`.

🎯 Practical Laboratory Objective
Understand why JavaScript's single-threaded runtime relies on non-blocking async promises for network I/O, avoiding browser UI freezing.

// 1. Promise Creator with Asynchronous Delay
function fetchStudentData(shouldSucceed) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (shouldSucceed) {
        resolve({ id: 101, name: "Shaik Roshan", role: "Developer" });
      } else {
        reject(new Error("503 Network Timeout Server Error"));
      }
    }, 1500);
  });
}

// 2. Async/Await Consumer with Try/Catch
async function handleRequest() {
  try {
    const data = await fetchStudentData(true);
    console.log("Received payload:", data);
  } catch (error) {
    console.error("Caught error:", error.message);
  }
}
