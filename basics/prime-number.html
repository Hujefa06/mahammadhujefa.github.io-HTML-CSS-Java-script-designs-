Prime Number Checker (Trial Division & O(√n))

Demonstrates the primality test algorithm checking whether an integer n > 1 has only two distinct factors (1 and itself). Optimized with O(√n) upper bound loop limit.

🎯 Practical Laboratory Objective
Understand algorithm time complexity optimization: checking factors only up to √n rather than checking all numbers up to n.
⚡ Live Primality Verifier
Working Demo
Primality Proof:
29 is a PRIME number. (No divisors between 2 and √29 ≈ 5.38) 
// Optimized O(sqrt(n)) Primality Test
function isPrime(n) {
  if (n <= 1) return false;
  if (n <= 3) return true;
  if (n % 2 === 0 || n % 3 === 0) return false;

  for (let i = 5; i * i <= n; i += 6) {
    if (n % i === 0 || n % (i + 2) === 0) {
      return false;
    }
  }
  return true;
}
