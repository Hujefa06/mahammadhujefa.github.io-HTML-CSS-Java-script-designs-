JS-14 Arrays

Array Sum & Average Calculation

Demonstrates the aggregation of numerical elements inside an array: calculating the accumulated total sum and arithmetic mean using both a for-loop and the functional `Array.prototype.reduce()` method.

🎯 Practical Laboratory Objective
Understand how reduce((accumulator, current) => accumulator + current, 0) accumulates complex arrays into single scalar outputs.

Working Demo
Statistical Breakdown:
// Functional Implementation using Array.prototype.reduce
function getArrayStats(numbers) {
  const sum = numbers.reduce((acc, curr) => acc + curr, 0);
  const average = numbers.length > 0 ? (sum / numbers.length) : 0;

  return { sum, average, count: numbers.length };
}
