JS-09 Strings

Palindrome Verifier (Strings & Numbers)

Demonstrates palindrome checking algorithms for both strings and numeric inputs, ignoring punctuation/spaces and casing, using both two-pointer index scanning and string reversal methods.

🎯 Practical Laboratory Objective
Understand string normalization via regex, character array operations (`split().reverse().join()`), and two-pointer character symmetry verification.
⚡ Live Palindrome Tester
Working Demo
Verification Result:
"A man a plan a canal Panama" is a valid PALINDROME! 
function isPalindrome(str) {
  // Normalize string: strip non-alphanumeric chars & lowercase
  const clean = str.toString().toLowerCase().replace(/[^a-z0-9]/g, '');
  const reversed = clean.split('').reverse().join('');
  return clean === reversed;
}
