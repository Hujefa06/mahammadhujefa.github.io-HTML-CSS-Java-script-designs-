JS-16 Strings

JavaScript String Methods Explorer

Demonstrates built-in methods on JavaScript String primitives: length, toUpperCase(), toLowerCase(), charAt(), slice(), substring(), replace(), includes(), trim(), and split().

🎯 Practical Laboratory Objective
Understand string immutability in JavaScript (methods return new strings rather than mutating the original) and master string slicing and tokenization.
