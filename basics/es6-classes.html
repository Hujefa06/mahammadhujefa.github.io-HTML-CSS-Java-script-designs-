JS-17 OOP

ES6 Classes and Object-Oriented Inheritance

Demonstrates Object-Oriented Programming (OOP) in ECMAScript 6: class declarations, constructor methods, instance getters/setters, class inheritance using `extends`, and parent constructor delegation using `super()`.

🎯 Practical Laboratory Objective
Understand prototypical inheritance underneath ES6 class syntax sugar, method overriding (polymorphism), and encapsulation of student academic data models.
⚡ Live OOP Class Instantiation Workbench
Working Demo
Object Instance Inspection:
// Base Class
class Person {
  constructor(name) {
    this.name = name;
  }
  introduce() {
    return `Hello, my name is ${this.name}.`;
  }
}

// Subclass Inheriting from Person
class Student extends Person {
  constructor(name, department, gpa) {
    super(name); // Delegates to parent constructor
    this.department = department;
    this.gpa = gpa;
  }
  getAcademicStatus() {
    return this.gpa >= 8.5 ? "First Class with Distinction" : "Standard Passing";
  }
}
