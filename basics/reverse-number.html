Reverse Integer and String Inversion

Demonstrates the inversion of numbers and text strings: pure mathematical digit extraction using modulo and division arithmetic (`n % 10` and `Math.floor(n / 10)`), alongside JavaScript string character reversal.

🎯 Practical Laboratory Objective
Understand mathematical while-loop digit reversal without converting numbers into strings, and handle negative integer signs correctly.

// 1. Pure Arithmetic Integer Reversal
function reverseInteger(num) {
  let isNegative = num < 0;
  let n = Math.abs(num);
  let reversed = 0;

  while (n > 0) {
    let digit = n % 10;
    reversed = (reversed * 10) + digit;
    n = Math.floor(n / 10);
  }

  return isNegative ? -reversed : reversed;
}

// 2. Generic String Reversal
function reverseString(str) {
  return str.split("").reverse().join("");
}
