Find Largest Among Three Numbers

Demonstrates conditional logical decision-making using relational comparison operators (>, >=), nested if-else ladders, ternary expressions, and the native Math.max() function.

🎯 Practical Laboratory Objective
Understand multi-way conditional branching logic and evaluate equality edge cases where two or all three values are identical.

// Method 1: Conditional If-Else Ladder
function findLargest(a, b, c) {
  if (a >= b && a >= c) {
    return a;
  } else if (b >= a && b >= c) {
    return b;
  } else {
    return c;
  }
}

// Method 2: Native Math.max API
const maxVal = Math.max(a, b, c);
