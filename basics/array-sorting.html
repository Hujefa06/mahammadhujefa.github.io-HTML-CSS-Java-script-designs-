JS-13 Arrays

Array Sorting: Bubble Sort & Array.prototype.sort()

Demonstrates sorting arrays of numbers and text in ascending and descending orders: comparing classic Bubble Sort with adjacent swap passes against modern V8 TimSort using numeric comparison callback functions `(a, b) => a - b`.

🎯 Practical Laboratory Objective
Understand why JavaScript's default `.sort()` converts numbers into strings (e.g. "100" comes before "25"), and learn to supply custom compare functions.

// 1. Native Array.prototype.sort with Numeric Comparator
const ascending  = [...numbers].sort((a, b) => a - b);
const descending = [...numbers].sort((a, b) => b - a);

// 2. Classical Bubble Sort Algorithm
function bubbleSort(arr) {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    for (let j = 0; j < n - i - 1; j++) {
      if (arr[j] > arr[j + 1]) {
        // Swap adjacent elements
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
      }
    }
  }
  return arr;
}
