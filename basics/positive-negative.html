JS-05 Logic

Check Positive, Negative or Zero

Demonstrates numerical classification using comparative conditional branches (> 0, < 0, === 0) and the built-in Math.sign() numeric utility.

🎯 Practical Laboratory Objective
Understand tripartite numeric evaluation logic and learn how Math.sign() returns 1, -1, or 0.
⚡ Live Sign Evaluator
Working Demo
Evaluation Result:
-15.5 is a NEGATIVE number (< 0) 
function checkNumberSign(n) {
  if (n > 0) {
    return "Positive";
  } else if (n < 0) {
    return "Negative";
  } else {
    return "Zero";
  }
}

// Alternatively using Math.sign(n) which returns 1, -1, or 0
