Even or Odd Number Verifier

Demonstrates the division remainder test using the modulus operator (% 2) and bitwise AND (& 1) to determine parity of positive and negative integers.

🎯 Practical Laboratory Objective
Understand parity classification, mathematical remainder properties, and bitwise parity checking for high-speed integer validation.

Working Demo
Parity Verification Result:
42 is an EVEN number (42 % 2 === 0) 
// Method 1: Modulo Arithmetic Operator
function isEven(n) {
  return n % 2 === 0;
}

// Method 2: Bitwise Fast Parity
function isEvenBitwise(n) {
  return (n & 1) === 0;
}
