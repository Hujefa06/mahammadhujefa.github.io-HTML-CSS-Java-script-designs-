Factorial Calculation (n!) Iterative & Recursive

Demonstrates the calculation of factorial n! = n × (n-1) × ... × 1, covering boundary cases (0! = 1, negative inputs undefined), showing the step-by-step expansion product.

🎯 Practical Laboratory Objective
Compare iterative loop execution (O(1) memory space) versus call stack recursion (O(n) memory space) for combinatorial math problems.
⚡ Live Factorial Engine
Working Demo
Expansion and Final Value:
6! = 6 × 5 × 4 × 3 × 2 × 1 = 720 
// Iterative Approach (Preferred for performance)
function factorial(n) {
  if (n < 0) return "Undefined for negative integers";
  if (n === 0 || n === 1) return 1;

  let result = 1;
  for (let i = 2; i <= n; i++) {
    result *= i;
  }
  return result;
}

// Recursive Approach
function factorialRecursive(n) {
  if (n < 0) return "Undefined";
  if (n === 0) return 1;
  return n * factorialRecursive(n - 1);
}
