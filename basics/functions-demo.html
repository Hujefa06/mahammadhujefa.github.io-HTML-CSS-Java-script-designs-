JS-15 Functions

Function Declarations, Expressions & ES6 Arrow Functions

Demonstrates the evolution of functions in JavaScript: traditional function declarations, anonymous function expressions, default parameter values, and modern ES6 concise arrow functions with lexical `this`.

🎯 Practical Laboratory Objective
Understand function hoisting differences between declarations and expressions, implicit return syntax in one-line arrow functions, and parameter rest syntax.

Working Demo
Execution Results:
// 1. Function Declaration (Hoisted)
function calculateSquare(n) {
  return n * n;
}

// 2. Function Expression
const calculateCube = function(n) {
  return n * n * n;
};

// 3. ES6 Arrow Function (Concise implicit return)
const calculateDouble = n => n * 2;
