JS-12 Arrays

Find Largest & Smallest Element in an Array

Demonstrates linear scan traversal to locate the minimum and maximum numeric values in a dataset, tracking both element values and their zero-based array indices.

🎯 Practical Laboratory Objective
Understand array iteration mechanics, initialization of sentinel min/max markers, and the Math.min(...array) spread operator syntax.

// Method 1: Iterative O(n) Scan
function findMinMax(arr) {
  let min = arr[0];
  let max = arr[0];

  for (let i = 1; i < arr.length; i++) {
    if (arr[i] < min) min = arr[i];
    if (arr[i] > max) max = arr[i];
  }
  return { min, max };
}

// Method 2: Modern Math Spread Operator
const minVal = Math.min(...arr);
const maxVal = Math.max(...arr);
