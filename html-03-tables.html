HTML-03 Forms & Tables

HTML Tables with Rows, Columns & Merged Cells

Demonstrates the construction of structured tabular datasets using table headers (<th>), table rows (<tr>), standard table data cells (<td>), caption, and cell merging using colspan and rowspan.

🎯 Practical Laboratory Objective
Understand table syntax, row/column alignment, border formatting, and how to effectively merge cells across columns (colspan) and rows (rowspan) for academic grade reports.
