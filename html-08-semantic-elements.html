HTML-08 Layout & Semantic

Semantic HTML5 Document Structure

Demonstrates the architectural layout of modern websites using semantic tags (<header>, <nav>, <main>, <section>, <article>, <aside>, and <footer>) to enhance screen reader accessibility and search engine indexing.

🎯 Practical Laboratory Objective
Understand the transition from non-semantic division containers (<div>) to meaningful semantic HTML5 tags that communicate purpose to search crawlers, browser engines, and assistive devices.
