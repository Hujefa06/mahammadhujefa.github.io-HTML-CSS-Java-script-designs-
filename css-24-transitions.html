CSS-24 Effects

CSS Transitions and Timing Acceleration Curves

Demonstrates the transition shorthand: transition-property, transition-duration, transition-timing-function (linear, ease, ease-in, ease-out, custom cubic-bezier), and transition-delay.

🎯 Practical Laboratory Objective
Understand how timing curves dictate natural physical motion acceleration, and compare mathematical cubic-bezier curves versus uniform linear movement.

/* Transition Shorthand: property | duration | timing | delay */
.button-animated {
  background-color: #4f46e5;
  transform: translateY(0);
  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

.button-animated:hover {
  background-color: #4338ca;
  transform: translateY(-4px);
  box-shadow: 0 10px 20px rgba(79, 70, 229, 0.3);
