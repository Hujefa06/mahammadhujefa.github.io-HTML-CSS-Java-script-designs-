CSS-02 Foundation

CSS Color Formats and Alpha Transparency

Demonstrates modern CSS color representations: Hexadecimal (#RRGGBB), RGB (rgb), RGBA with alpha transparency, HSL (hue, saturation, lightness), and CSS opacity channels with WCAG contrast verification.

🎯 Practical Laboratory Objective
Understand chromatic color spaces in CSS, why HSL provides superior mathematical control for generative palettes, and the difference between rgba() alpha channel vs element-level opacity.
