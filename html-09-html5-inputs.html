HTML-09 Forms & Tables

HTML5 Specialized Input Types & Datalist

Demonstrates modern HTML5 input controls including color picker, date/time pickers, range slider with live readout, numeric steppers with min/max constraints, search with clear triggers, URL/Tel validators, and autocomplete suggestions using <datalist>.

🎯 Practical Laboratory Objective
Evaluate the client-side validation, mobile on-screen keyboard tailoring, and user experience enhancements introduced by HTML5 specialized input types and pre-defined datalist options.
⚡ Live Interactive Controls
Working Demo
Selected Hex: #4f46e5
Current Value: 65%
Constraint: Min 1, Max 10, Step 1
Native calendar picker
Features native clear icon (x)

<!-- Color picker -->
<input type="color" id="favcolor" name="favcolor" value="#4f46e5">

<!-- Range slider -->
<input type="range" id="volume" name="volume" min="0" max="100" value="65">

<!-- Number input with range constraints -->
<input type="number" min="1" max="10" step="1" value="4">

<!-- Date picker -->
<input type="date" name="examdate">

<!-- Datalist input with autocomplete suggestions -->
<input list="courseList" name="course" placeholder="Select or type...">
<datalist id="courseList">
  <option value="Java Programming">
  <option value="HTML & Web Development">
  <option value="Database Engineering">
</datalist>
