CSS-21 Foundation

CSS Measurement Units: Absolute vs Relative

Demonstrates the distinction between absolute units (px) and relative scalable units: rem (relative to root html font size), em (relative to parent font size), % (percentage of parent container), and viewport units (vh, vw).

🎯 Practical Laboratory Objective
Understand why `rem` units ensure user browser accessibility preferences (such as large font settings) are respected, unlike rigid hardcoded pixel values.
⚡ Live Unit Comparison Matrix
Working Demo
Unit Category Reference Base Primary Use Case
px Absolute 1 device pixel dot Fine border lines, fixed iconography
rem Relative (Root) Root <html> font size (usually 16px) Typography, padding, margins, layout spacing
em Relative (Local) Immediate parent font size Button icons scaling relative to button text
% Relative (Parent) Direct parent box dimension Grid column widths, responsive images
vw / vh Viewport 1% of window width / height Full screen hero banners, modal backdrops 
/* 1rem = 16px (Assuming default browser setting) */
h1 {
  font-size: 2rem;       /* 32px equivalent, but accessible */
  margin-bottom: 1rem;   /* 16px vertical rhythm */
}

/* Viewport Full-Screen Section */
.hero-fullscreen {
  width: 100vw;
  height: 100vh;
}

/* Button with em-scaled inner padding */
.button {
  font-size: 1.2rem;
  padding: 0.5em 1em;    /* Automatically scales if font-size changes */
}
