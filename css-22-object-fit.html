CSS-22 Foundation

Media Aspect Ratio Control with object-fit

Demonstrates how replaced media elements (<img> and <video>) respond when forced into fixed aspect ratio boxes using object-fit: fill, contain, cover, none, and scale-down.

🎯 Practical Laboratory Objective
Understand why `object-fit: cover` is essential for avatar cards and responsive image grids, preserving aspect ratios without distortion or stretching.
⚡ Live Aspect Ratio Behavior Matrix
Working Demo
object-fit: cover Fills box, crops excess
object-fit: contain Fits whole image with letterbox
object-fit: fill Stretches & distorts 
/* Avatar Image that never stretches */
.profile-thumbnail {
  width: 120px;
  height: 120px;
  border-radius: 50%;
  object-fit: cover;
  object-position: center top; /* Focuses crop towards top of face */
}

/* Product image showcase fitting complete packaging */
.product-hero-image {
  width: 100%;
  height: 400px;
  object-fit: contain;
}
