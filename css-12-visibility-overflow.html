CSS-12 Box Model

Visibility Hidden vs Display None & Overflow Handling

Demonstrates the critical distinction between removing an element from the render flow (display: none) versus hiding pixels while preserving layout space (visibility: hidden), alongside overflow control (visible, hidden, scroll, auto).

🎯 Practical Laboratory Objective
Understand how layout reflow occurs when removing elements, and master scroll clipping for modals, code panes, and tables.

2. overflow: auto Scroll Container

Scrollable Content Area:
When text or embedded items exceed the bounding box height of 120px, overflow-y: auto automatically provides smooth browser scrollbars without distorting sibling page elements. Try scrolling this card! 
/* display: none removes element entirely from layout */
.item-removed {
  display: none;
}

/* visibility: hidden hides element but reserves its physical space */
.item-invisible {
  visibility: hidden;
}

/* overflow: auto introduces scrollbars strictly when content overflows */
.scroll-pane {
  max-height: 200px;
  overflow-y: auto;
}
