setTimeout vs setInterval Asynchronous Timers

Demonstrate delayed execution using setTimeout and continuous polling using setInterval, along with id tracking and cancellation via clearTimeout and clearInterval.

⏲️ Asynchronous Timer Playground
BOM Timing APIs

1. setTimeout() - One-Shot Delay

Fires a callback function once after a specified 3-second delay.

Status: Idle

2. setInterval() - Recurring Ticker

Repeats a callback function indefinitely at 1-second intervals.

0s 
// 1. One-Shot Timeout
let timeoutId = setTimeout(() => {
  console.log("3 seconds elapsed!");
}, 3000);

// Cancel timeout before it fires
clearTimeout(timeoutId);

// 2. Recurring Interval
let count = 0;
let intervalId = setInterval(() => {
  count++;
  console.log(`Tick count: ${count}`);
}, 1000);

// Cancel recurring interval
clearInterval(intervalId);
