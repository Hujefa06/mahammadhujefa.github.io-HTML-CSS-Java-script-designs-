Window Dialogs: alert(), confirm(), prompt()

Trigger native browser synchronous modal dialogs: informative alerts (no return), binary confirmations (returns boolean true/false), and string prompt inputs.

💬 Browser Dialog Triggers
Modal Dialogs

1. window.alert()

Displays an informational message box with an OK button. Freezes code execution until dismissed.

Return: undefined

2. window.confirm()

Prompts user with OK and Cancel buttons. Returns true if OK is pressed, false if cancelled.

Return: Waiting...

3. window.prompt()

Displays a text entry box. Returns the user's typed string, or null if Cancel is clicked.

Return: Waiting...
// 1. Alert (no return value)
window.alert("Laboratory record submitted!");

// 2. Confirm (returns boolean)
const userConfirmed = window.confirm("Are you sure you want to proceed?");
if (userConfirmed) {
  console.log("User selected OK (true)");
} else {
  console.log("User selected Cancel (false)");
}

// 3. Prompt (returns string or null)
const studentName = window.prompt("Please enter student name:", "Shaik Roshan");
if (studentName !== null) {
  console.log("Entered:", studentName);
} else {
  console.log("User cancelled prompt");
}
