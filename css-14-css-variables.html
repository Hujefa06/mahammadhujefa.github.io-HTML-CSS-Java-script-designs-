CSS-14 Foundation

CSS Custom Properties (Variables) & Theming

Demonstrates the declaration and inheritance of CSS custom properties using `--name` syntax and the `var(--name, fallback)` function, highlighting real-time runtime theme switching without rewriting stylesheet rules.

🎯 Practical Laboratory Objective
Understand lexical scoping of variables, global :root tokens vs component-scoped variables, and how changing a single variable updates all associated elements across the DOM tree.
⚡ Live Theme Switcher Sandbox
Working Demo

Theme Container (--theme-bg / --theme-text)

All colors within this component are dynamically inherited from 5 core CSS variables.

Nested Component Card

Accent Color Token: var(--theme-accent) 

/* Declare Global CSS Variables in :root */
:root {
  --primary-color: #4f46e5;
  --bg-color: #ffffff;
  --text-color: #0f172a;
}

/* Dark Theme Overrides */
[data-theme="dark"] {
  --bg-color: #0f172a;
  --text-color: #f8fafc;
  --primary-color: #38bdf8;
}

/* Consumer elements reference tokens cleanly */
body {
  background-color: var(--bg-color);
  color: var(--text-color);
}
.button-cta {
  background-color: var(--primary-color);
}
