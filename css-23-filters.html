CSS-23 Effects

CSS Graphical Filters Playground

Demonstrates GPU-accelerated graphical filter functions directly in CSS: blur, brightness, contrast, grayscale, hue-rotate, invert, opacity, and sepia without external graphics editing software.

🎯 Practical Laboratory Objective
Master real-time visual post-processing on web elements, and understand hardware acceleration performance advantages when chaining CSS filter effects.
⚡ Live Filter Sandbox
Working Demo
FILTER FX
filter: blur(0px) grayscale(0%) hue-rotate(0deg) contrast(100%); 
/* Chained Graphical Filters */
.filtered-artwork {
  filter: blur(2px) 
          grayscale(50%) 
          hue-rotate(90deg) 
          contrast(120%);
  transition: filter 0.3s ease;
}

/* Hover reveal to vibrant color */
.filtered-artwork:hover {
  filter: none;
}
