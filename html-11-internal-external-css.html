HTML-11 Fundamentals

Integration of Inline, Internal & External CSS

Demonstrates the three primary methods for binding Cascading Style Sheets to an HTML document: Inline styles via the style attribute, Internal styles via the <style> tag in the head, and External styles linked via <link rel="stylesheet">, highlighting specificity order and priority.

🎯 Practical Laboratory Objective
Understand the architectural separation of structure (HTML) and presentation (CSS), and discover how the CSS cascade prioritizes inline styles over internal and external rules.
⚡ Live Styling Priority Comparison
Working Demo
Priority 1: Highest

Inline CSS

Applied directly to an HTML element using the style="..." attribute. Overrides external and internal stylesheet rules.

<div style="color: red;">
Priority 2: Medium

Internal CSS

Defined within a <style> block located in the document's <head>. Applies exclusively to this single HTML page.

<style> .card { ... } </style>
Priority 3: Global Base

External CSS

Linked via <link rel="stylesheet" href="...">. Best practice for modular, cached, and maintainable site-wide styling.

<link rel="stylesheet" href="style.css"> 
<!DOCTYPE html>
<html lang="en">
<head>
  <!-- 1. External CSS Link -->
  <link rel="stylesheet" href="style.css">

  <!-- 2. Internal CSS Style Block -->
  <style>
    .internal-box {
      background: #f0fdf4;
      border: 2px solid #16a34a;
      color: #14532d;
    }
  </style>
</head>
<body>

  <!-- 3. Inline CSS applied via attribute -->
  <div style="background: #fff1f2; color: #9f1239;">
    Inline Styled Element (Overrides external and internal)
  </div>

  <div class="internal-box">
    Internal Styled Element
  </div>

</body>
</html>
