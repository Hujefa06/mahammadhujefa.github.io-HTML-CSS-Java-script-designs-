Text Shadow Glow Effect

LUMINESCENT GLOW

CSS multi-stop text shadow creates depth and ambient backlighting.

/* Import Google Fonts with Swap display */
@import url('https://fonts.googleapis.com/css2?family=Playfair+Display:ital,wght@0,600;1,400&display=swap');

/* Font Family Stack with System Fallbacks */
.editorial-title {
  font-family: 'Playfair Display', Georgia, 'Times New Roman', serif;
  font-size: 2rem;
  line-height: 1.3;
}

/* Multi-layer Text Shadow Glow */
.glow-text {
  color: #ffffff;
  text-shadow: 0 0 10px rgba(99, 102, 241, 0.8),
               0 0 20px rgba(99, 102, 241, 0.4);
}
