HTML-05 Forms & Tables

Comprehensive Student Registration Form

Demonstrates the creation of an extensive HTML input form incorporating text, email, password, telephone, date, gender radio buttons, interests checkboxes, select dropdowns, file upload, and textarea with submit and reset controls.

🎯 Practical Laboratory Objective
Understand form grouping (<fieldset>, <legend>), input attribute constraints (required, minlength, pattern), and accessibility pairing with explicit <label for="..."> bindings.
