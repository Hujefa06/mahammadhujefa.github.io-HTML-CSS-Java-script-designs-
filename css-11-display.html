CSS-11 Box Model

CSS Display Properties (Block, Inline, Inline-Block)

Demonstrates the fundamental CSS rendering flow models: display block (fills full available horizontal width and forces line breaks), display inline (flows with text, ignores explicit width/height), and display inline-block (flows inline while respecting width/height).

🎯 Practical Laboratory Objective
Understand how browser render engines calculate document flow, why inline elements cannot accept vertical margins, and how inline-block bridges the gap.

/* Block: Starts new line, takes full width */
.block-item {
  display: block;
  width: 100%;
}

/* Inline: Stays in text flow, ignores width/height */
.inline-item {
  display: inline;
}

/* Inline-Block: Stays in line, accepts width & height */
.inline-block-item {
  display: inline-block;
  width: 140px;
  height: 60px;
}
