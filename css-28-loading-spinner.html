CSS-28 Effects

Modern Animated CSS Loading Spinners

Demonstrates the implementation of pure CSS asynchronous wait indicators: circular ring spinner with partial border coloring, staggered delay bouncing dots, and content placeholder shimmer skeletons.

🎯 Practical Laboratory Objective
Master negative animation-delay for synchronizing multi-element wave patterns and implement content shimmer loaders for progressive web application loading states.
⚡ Live Loader Component Suite
Working Demo
Circular Ring Loader border-top rotation
Bouncing 3-Dot Wave Staggered animation-delay
Shimmer Skeleton Loader Moving linear-gradient 
/* Circular Spinner */
.spinner {
  width: 48px;
  height: 48px;
  border: 4px solid #e2e8f0;
  border-top-color: #4f46e5;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}
@keyframes spin {
  to { transform: rotate(360deg); }
}

/* Staggered Pulsing Dots */
.dot:nth-child(1) { animation-delay: -0.32s; }
.dot:nth-child(2) { animation-delay: -0.16s; }

/* Shimmer Skeleton */
.skeleton {
  background: linear-gradient(90deg, #e2e8f0 25%, #f1f5f9 50%, #e2e8f0 75%);
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
}
