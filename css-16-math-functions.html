CSS Math: calc(), min(), max() & clamp()

Demonstrates mathematical operations directly within CSS properties: calc() for mixing dissimilar units (e.g. 100% minus fixed sidebar pixels), min() for ceiling bounds, max() for floor safeguards, and clamp() for fluid scalable typography without media queries.

🎯 Practical Laboratory Objective
Understand how clamp(min, ideal, max) eliminates dozens of repetitive media query breakpoints by providing continuous, mathematically smooth scaling.

Working Demo

1. Fluid clamp() Typography

font-size: clamp(1.25rem, 3vw + 0.5rem, 2.5rem)
Fluid Scalable Heading

Scales dynamically with browser window width, clamped safely between 1.25rem and 2.5rem.

2. calc() Column Subtraction

width: calc(100% - 136px)
Sidebar (120px)
calc(100% - 136px)

Combines dynamic percentages with fixed physical pixel offsets effortlessly.

3. min() and max() Functions

width: min(100%, 350px)
Caps width at 350px, but gracefully takes 100% when parent is smaller! 
/* Fluid Typography using clamp() */
.fluid-title {
  /* syntax: clamp([min-size], [preferred-fluid-size], [max-size]) */
  font-size: clamp(1.25rem, 3vw + 0.5rem, 2.5rem);
}

/* Mixed Unit Subtraction using calc() */
.content-pane {
  width: calc(100% - 240px); /* 100% minus fixed sidebar */
}

/* Bounds using min() and max() */
.responsive-card {
  width: min(90vw, 600px); /* Never wider than 600px or 90% of screen */
  padding: max(16px, 2vw);  /* Never smaller than 16px */
}
