CSS-17 Layout

CSS Positioning: Static, Relative, Absolute, Fixed & Sticky

Demonstrates the 5 positioning modes of CSS: static (normal flow), relative (offset relative to self without disrupting siblings), absolute (pinned to nearest positioned ancestor), fixed (pinned to viewport), and sticky (toggles relative to fixed during scroll).

🎯 Practical Laboratory Objective
Understand why a parent must declare `position: relative` to act as an anchor frame for child `position: absolute` elements, and how `position: sticky` powers persistent table headers.

/* Relative Parent Anchor */
.parent-container {
  position: relative;
}

/* Absolute Child: Anchors to nearest non-static parent */
.child-badge {
  position: absolute;
  top: 12px;
  right: 12px;
}

/* Fixed: Locks to browser viewport window */
.fixed-floating-btn {
  position: fixed;
  bottom: 24px;
  right: 24px;
}

/* Sticky: Behaves relative until scroll reaches threshold */
.sticky-nav {
  position: sticky;
  top: 0;
  z-index: 10;
}
