Float, Clear and Parent Clearfix Micro-Hack

Demonstrates the float property (left, right) used for wrapping editorial prose around illustrations, the collapse of parent container heights caused by floated children, and the classic clearfix pseudo-element solution.

🎯 Practical Laboratory Objective
Understand why floating an element pulls it out of the parent's normal height calculation and how the `clearfix` hack forces the container to encompass floated contents.

Floated Left (float: left)

Editorial Flow Surrounding Floated Media

The text content flows naturally around the right and bottom contours of the floated box. Because the parent container has the clearfix class applied via its ::after pseudo-element, the parent maintains its full calculated height and will not let subsequent page elements collide. 

/* Floated Media Element */
.floated-img {
  float: left;
  margin: 0 16px 8px 0;
}

/* Clearfix Micro-Hack for Parent Containers */
.clearfix::after {
  content: "";
  display: table;
  clear: both;
}
