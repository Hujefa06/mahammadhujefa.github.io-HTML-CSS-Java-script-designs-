CSS-01 Foundation

CSS Selectors and Combinator Relationships

Demonstrates relational selector targeting: descendant selector (space), direct child selector (>), adjacent sibling selector (+), and general sibling selector (~), highlighting parent-child boundaries.

🎯 Practical Laboratory Objective
Understand how combinators allow precision targeting of DOM elements based on document tree relationships without requiring redundant inline classes.
⚡ Live Combinator Showcase
Working Demo
Container (.parent-box)
.direct-child (Targeted by .parent-box > .direct-child)
Intermediate Sub-wrapper
.nested-descendant (Targeted by .parent-box .nested-descendant)
Reference Anchor Element (.base-element)
.adjacent-sibling (Immediately follows anchor: .base-element + .adjacent-sibling)
.general-sibling (Follows anywhere after anchor: .base-element ~ .general-sibling) 
/* 1. Direct Child Combinator: Targets immediate children only */
.parent-box > .direct-child {
  background: #dbeafe;
  border: 1.5px solid #3b82f6;
}

/* 2. Descendant Combinator: Targets any nested descendant */
.parent-box .nested-descendant {
  background: #fef3c7;
}

/* 3. Adjacent Sibling: Targets immediately following sibling */
.base-element + .adjacent-sibling {
  background: #dcfce7;
}

/* 4. General Sibling: Targets all subsequent siblings */
.base-element ~ .general-sibling {
  background: #f3e8ff;
}
