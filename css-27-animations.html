CSS-27 Effects

Multi-step CSS Keyframe Animations (@keyframes)

Demonstrates complex timeline animations utilizing the @keyframes rule: defining 0% to 100% states, iteration-count: infinite, animation-direction: alternate, animation-fill-mode, and interactive play-state pause controls.

🎯 Practical Laboratory Objective
Understand timeline percentages, intermediate keyframe stages, and how animation-play-state enables instant pausing of animated elements.

/* Declare Keyframe Timeline */
@keyframes bounce {
  0%, 100% {
    transform: translateY(0);
  }
  50% {
    transform: translateY(-40px);
  }
}

/* Bind Animation to Element */
.bouncing-ball {
  animation-name: bounce;
  animation-duration: 1.2s;
  animation-iteration-count: infinite;
  animation-timing-function: ease-in-out;
}

/* Pause Control */
.paused {
  animation-play-state: paused;
}
