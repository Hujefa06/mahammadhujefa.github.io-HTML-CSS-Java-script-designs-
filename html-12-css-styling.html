CSS Selectors, Colors, Typography & Box Model

Demonstrates the application of elemental, class, and ID selectors, modern color formats (HEX, RGB, HSL), web typography with Google Fonts, and the foundational CSS Box Model (content, padding, border, margin).

Understand how browser layout engines calculate component dimensions using box model layers, and master CSS selectors for granular element targeting.

Modern Color Models

/* Box Model Configuration */
.card-component {
  width: 300px;
  margin: 20px auto;       /* Outer spacing */
  border: 2px solid #cbd5e1;/* Boundary line */
  padding: 16px;           /* Inner clearance */
  background: #ffffff;     /* Content backdrop */
  box-sizing: border-box;  /* Includes padding/border in width */
}

/* Color Model Implementations */
.hex-color  { background-color: #4f46e5; color: #ffffff; }
.rgba-color { background-color: rgba(6, 182, 212, 0.8); }
.hsl-color  { background-color: hsl(245, 82%, 67%); }
