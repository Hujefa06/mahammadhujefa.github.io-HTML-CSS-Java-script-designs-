HTML-02 Fundamentals

Ordered, Unordered and Description Lists

Demonstrates the creation and customization of numbered ordered lists (<ol>), bulleted unordered lists (<ul>), and definition/description lists (<dl>, <dt>, <dd>) with nesting.

🎯 Practical Laboratory Objective
Master the different listing structures in HTML5, their default bullet types, type attributes (numeric, alphabetic, roman), and description pairings for terms and definitions.

Web Terminology Glossary:

HTML
HyperText Markup Language: the standard markup language for documents designed to be displayed in a web browser.
CSS
Cascading Style Sheets: stylesheet language used for describing the presentation of a document.
DOM
Document Object Model: programmatic API representation for HTML documents.
