CSS-20 Foundation

Custom Cursor Types and Accessible Outlines

Demonstrates the spectrum of user affordance cursors (pointer, crosshair, grab, grabbing, not-allowed, zoom-in, wait), and the distinction between borders (which impact the box model) versus outlines with outline-offset.

🎯 Practical Laboratory Objective
Learn how to convey UI state affordances with contextual cursor feedback, and use non-disruptive keyboard focus rings with outline-offset for WCAG accessibility.

2. Outline vs Border with outline-offset:

Notice how the cyan dashed outline floats 6px outside the button without shifting any surrounding elements! 

/* State-driven Cursors */
.draggable-card { cursor: grab; }
.disabled-button { cursor: not-allowed; }

/* Accessible Focus Ring with Outline Offset */
button:focus-visible {
  outline: 3px solid #6366f1;
  outline-offset: 4px; /* Floating space between element and focus ring */
}
