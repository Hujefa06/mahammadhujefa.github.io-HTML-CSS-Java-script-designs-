CSS-35 Layout

12-Column Responsive CSS Grid Architecture

Demonstrates modern CSS Grid layout design systems: 12-column track divisions using repeat(12, 1fr), fractional sizing, spanning column spans (span 12, span 6, span 4, span 3), and fluid auto-fitting.

🎯 Practical Laboratory Objective
Understand how fractional `fr` units distribute available container space proportionally and replace complex float-based 12-column frameworks with native CSS Grid.

/* Native 12-Column CSS Grid */
.grid-container {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 16px;
}

/* Column Spans */
.col-12 { grid-column: span 12; }
.col-6  { grid-column: span 6; }
.col-4  { grid-column: span 4; }
.col-3  { grid-column: span 3; }

/* Responsive Auto-Collapse */
@media (max-width: 768px) {
  .col-6, .col-4, .col-3 {
    grid-column: span 12;
  }
}
