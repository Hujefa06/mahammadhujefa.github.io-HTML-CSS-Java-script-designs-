HTML-04 Fundamentals

Images and Hyperlinks in HTML

Demonstrates the inclusion of images using <img>, semantic figures with captions (<figure>, <figcaption>), external links with target="_blank", internal bookmark anchors, email links (mailto:), and telephone links (tel:).

🎯 Practical Laboratory Objective
Learn how to embed responsive web images with appropriate accessibility attributes (alt), and create robust navigation paths across internal document bookmarks and external web resources.
