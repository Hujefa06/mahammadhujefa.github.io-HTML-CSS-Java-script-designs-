Dark / Light Theme Persistence with LocalStorage

Save user theme preferences (Dark Mode, Light Mode, Cyberpunk) in localStorage so the preferred aesthetic persists seamlessly upon page refresh and subsequent visits.

This entire container state is synchronized with localStorage.getItem("app_theme"). Switch themes below, then refresh your web browser (F5) to verify state persistence! 

// 1. Apply theme and save preference to LocalStorage
function applyTheme(themeName) {
  // Update element class
  container.className = `theme-playground-box theme-${themeName}`;
  
  // Persist choice to localStorage
  localStorage.setItem("user_preferred_theme", themeName);
}

// 2. Load stored theme on initial page render
window.addEventListener("DOMContentLoaded", () => {
  const savedTheme = localStorage.getItem("user_preferred_theme") || "dark";
  applyTheme(savedTheme);
});
