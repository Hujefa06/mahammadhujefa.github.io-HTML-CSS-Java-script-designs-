Complex Objects & Arrays Storage via JSON

Since localStorage only accepts strings, learn how to serialize complex JavaScript objects and arrays using JSON.stringify() and deserialize with JSON.parse().

2. Deserialized Live JS Object:

const studentProfile = {
  name: "Shaik Roshan",
  roll: "22CS042",
  department: "Computer Science",
  skills: ["HTML5", "CSS3", "JavaScript"]
};

// 1. Serialize object to JSON string before storing
localStorage.setItem("user_profile", JSON.stringify(studentProfile));

// 2. Retrieve string and deserialize back to native object
const storedString = localStorage.getItem("user_profile");
const profileObj = JSON.parse(storedString);

console.log(profileObj.name); // "Shaik Roshan"
console.log(profileObj.skills[0]); // "HTML5"
