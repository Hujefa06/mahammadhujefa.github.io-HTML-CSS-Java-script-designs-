The Document Object Model (DOM) is an application programming interface for HTML and XML documents. It defines the logical structure of documents and the way a document is accessed and manipulated. With the Document Object Model, programmers can build documents, navigate their structure, and add, modify, or delete elements and content.

In modern web development, user preferences such as typography scaling, dark mode, and high-contrast color palettes are stored directly on the client machine using HTML5 Web Storage APIs. This ensures instantaneous page rendering tailored to individual accessibility requirements without unnecessary server overhead. 

const article = document.getElementById("articleContent");

// 1. Set font size and save to localStorage
function setFontSize(pxSize) {
  article.style.fontSize = pxSize + "px";
  localStorage.setItem("reader_font_size", pxSize);
}

// 2. Restore preference on load
window.addEventListener("DOMContentLoaded", () => {
  const savedSize = localStorage.getItem("reader_font_size") || 18;
  setFontSize(savedSize);
});
