LocalStorage vs SessionStorage vs HTTP Cookies

A direct technical comparison examining storage capacities (~5MB vs 4KB), expiration lifecycles, tab boundaries, and HTTP server transmission.

Feature Property localStorage sessionStorage HTTP Cookies
Capacity ~5MB - 10MB per origin ~5MB per origin 4KB (very small)

// 1. localStorage: persists indefinitely across tabs
localStorage.setItem("key_local", "Permanent Data");
console.log(localStorage.getItem("key_local"));

// 2. sessionStorage: dies immediately when browser tab is closed
sessionStorage.setItem("key_session", "Temporary Session Data");
console.log(sessionStorage.getItem("key_session"));

// 3. Document Cookies: transmitted automatically with HTTP requests
document.cookie = "username=ShaikRoshan; max-age=3600; path=/";
