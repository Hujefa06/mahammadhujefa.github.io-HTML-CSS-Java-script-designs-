CSS-15 Foundation

CSS Specificity Calculations & Cascade Hierarchy

Demonstrates how browser CSS cascade engines resolve competing declarations using the 4-part specificity vector: (Inline, ID, Class/Attribute/Pseudo-class, Element/Pseudo-element), and the exceptional override power of !important.

🎯 Practical Laboratory Objective
Understand why an ID selector always overrides ten chained classes, and how the Cascade decides winners when two selectors have identical specificity scores (order of appearance).

Interactive Collision Demonstration:

This paragraph has an ID (#target-paragraph), a class (.class-rule), and an element tag (p). The ID rule wins over the class rule! 

/* Specificity: (0, 0, 0, 1) - Low */
p {
  background-color: #64748b;
}

/* Specificity: (0, 0, 1, 0) - Overrides element rule */
.class-rule {
  background-color: #10b981;
}

/* Specificity: (0, 1, 0, 0) - Overrides class rule! */
#target-paragraph {
  background-color: #2563eb;
}

/* Specificity: Maximum override (Use sparingly) */
.danger-override {
  background-color: #ef4444 !important;
}
