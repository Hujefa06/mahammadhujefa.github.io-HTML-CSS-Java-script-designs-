HTML-01 Fundamentals

Basic HTML Webpage with Headings & Formatting

Demonstrates the fundamental building blocks of an HTML document, including document type declaration, hierarchical headings (h1 to h6), paragraphs, line breaks, horizontal rules, and inline text formatting tags.

🎯 Practical Laboratory Objective
Understand the structure of an HTML5 document and learn how to format text hierarchically using semantic heading levels and typographic elements such as <strong>, <em>, <mark>, <sub>, and <sup>.

Inline Formatting Tags

This text contains bold text using <strong>, italicized emphasis using <em>, and highlighted content using <mark>.

We can express scientific chemical formulas: Water is H2O (using <sub>).
We can express mathematical exponents: Einstein's equation is E = mc2 (using <sup>).

Text can also show deleted price: $100 and inserted price: $79 (using <del> and <ins>). 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Basic HTML Webpage</title>
</head>
<body>

  <!-- Heading Hierarchy -->
  <h1>Heading Level 1 (&lt;h1&gt;)</h1>
  <p>This is a standard paragraph introducing the document topic.</p>

  <h2>Heading Level 2 (&lt;h2&gt;)</h2>
  <h3>Heading Level 3 (&lt;h3&gt;)</h3>
  <h4>Heading Level 4 (&lt;h4&gt;)</h4>
  <h5>Heading Level 5 (&lt;h5&gt;)</h5>
  <h6>Heading Level 6 (&lt;h6&gt;)</h6>

  <hr>

  <!-- Text Formatting -->
  <p>This text contains <strong>bold text</strong> and <em>italicized text</em>.</p>
  <p>Chemical formula: H<sub>2</sub>O and Math formula: E = mc<sup>2</sup></p>
  <p>Important text can be <mark>highlighted with mark</mark>.</p>
  <p><del>Old Price: $100</del> <ins>New Price: $79</ins></p>

</body>
</html>
