Understand CSS Grid area positioning for full-height web application shells with responsive collapsing sidebars on mobile screens.

/* Modern 2-Column App Shell Grid */
.dashboard-shell {
  display: grid;
  grid-template-columns: 260px 1fr;
  min-height: 100vh;
}

/* Sidebar Navigation */
.sidebar {
  background-color: #0f172a;
  position: sticky;
  top: 0;
  height: 100vh;
}

/* Mobile Breakpoint: Collapse Sidebar */
@media (max-width: 768px) {
  .dashboard-shell {
    grid-template-columns: 1fr;
  }
  .sidebar {
    display: none;
  }
}
