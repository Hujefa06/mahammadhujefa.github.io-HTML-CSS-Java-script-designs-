Field Specific Rule Validators

Isolate specific validation logic for distinct input types: alphabetic names, Indian mobile numbers, age boundaries (18 to 60), standard postal PIN codes (6 digits), and URL web links.

1. Alphabetic Name Only Waiting

Rule: Letters and spaces only, 3+ characters.

2. 10-Digit Phone Waiting

Rule: Exact 10 digits starting with 6, 7, 8, or 9.

3. Age Range (18 - 60) Waiting

Rule: Numeric integer between 18 and 60 inclusive.

4. Postal PIN Code Waiting

Rule: Exactly 6 digits (first digit non-zero).
// 1. Alphabetic Name: only letters and spaces, at least 3 chars
const isValidName = (name) => /^[a-zA-Z\s]{3,}$/.test(name);

// 2. Mobile Phone: 10 digits starting with 6-9
const isValidPhone = (phone) => /^[6-9]\d{9}$/.test(phone);

// 3. Age Range: numeric 18 to 60
const isValidAge = (age) => {
  const num = parseInt(age);
  return !isNaN(num) && num >= 18 && num <= 60;
};

// 4. Postal PIN: 6 digits, first digit cannot be 0
const isValidPin = (pin) => /^[1-9][0-9]{5}$/.test(pin);
