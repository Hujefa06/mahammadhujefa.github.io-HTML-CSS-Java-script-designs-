CSS-08 Box Model

CSS Box Model & Margin Collapsing Mechanics

Demonstrates the anatomy of element layout geometry: Margin (outer gap), Border (stroke boundary), Padding (inner breathing room), and Core Content, plus the phenomenon of vertical margin collapse.

🎯 Practical Laboratory Objective
Understand how adjacent vertical margins collapse into the single largest margin value instead of adding together, and visualize concentric box model layers.
⚡ Live Box Model Architecture
Working Demo
Margin: Outer Clearance (24px)
Border: Structural Boundary (4px solid)
Padding: Content Breathing Room (20px)
Core Content Box (Text / Media)

Vertical Margin Collapse Demonstration

Box 1 has margin-bottom: 30px. Box 2 has margin-top: 20px. In standard CSS block flow, the total spacing is NOT 50px—it collapses to 30px (the maximum of both).

Box 1: margin-bottom: 30px
Box 2: margin-top: 20px (Space between boxes is max(30px, 20px) = 30px) 
/* Explicit Box Model Definition */
.element-box {
  margin: 24px;   /* Layer 1: Outermost transparent gap */
  border: 4px solid #ea580c; /* Layer 2: Boundary line */
  padding: 20px;  /* Layer 3: Inner clearance */
  width: 300px;   /* Layer 4: Content dimension */
}

/* Margin Collapsing Behavior */
.card-top    { margin-bottom: 30px; }
.card-bottom { margin-top: 20px; }
/* Resulting vertical distance between them equals 30px, not 50px */
