CSS-09 Box Model

Width, Height and Min/Max Dimension Constraints

Demonstrates the sizing engine of CSS: fixed dimensions (px), percentage fluid dimensions (%), max-width bounds for responsive safety, min-height vertical guarantees, and modern intrinsic sizing using fit-content.

🎯 Practical Laboratory Objective
Understand why `width: 100%; max-width: 600px;` is the golden rule of responsive container design, preventing layout overflow on mobile screens.

250px × 80px Fixed

2. Responsive Container (width: 100%; max-width: 500px;)

Expands up to 500px on desktops, but gracefully shrinks to 100% on small smartphone viewports without horizontal scrollbars.

3. Intrinsic Width (width: fit-content;)

Skins tightly around content text → 
/* Responsive Safe Container */
.container {
  width: 100%;           /* Fills parent on small screens */
  max-width: 1200px;     /* Caps width on ultrawide monitors */
  margin: 0 auto;        /* Center alignment */
}

/* Intrinsic Sizing */
.tag-badge {
  width: fit-content;    /* Clamps to exact text length */
}
