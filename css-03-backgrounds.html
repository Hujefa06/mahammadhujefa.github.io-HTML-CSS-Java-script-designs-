CSS-03 Foundation

CSS Background Properties and Parallax Attachment

Demonstrates the comprehensive background suite: background-color, background-image, background-size (cover vs contain), background-repeat (no-repeat, repeat), background-position, and fixed attachment effects.

🎯 Practical Laboratory Objective
Understand how background layers stack, how to construct geometric dot/grid patterns via gradient repeats, and how fixed attachment locks image coordinates to the viewport.

Created using radial-gradient tile repeat (16px x 16px).

background-attachment: fixed

Locks gradient coordinates to the browser viewport window.

/* Background Shorthand Syntax */
.hero-banner {
  background-color: #0f172a;
  background-image: url('banner.jpg');
  background-repeat: no-repeat;
  background-position: center center;
  background-size: cover;
  background-attachment: fixed; /* Parallax effect */
}

/* Repeating Pattern via Radial Gradients */
.pattern-grid {
  background-color: #f8fafc;
  background-image: radial-gradient(#cbd5e1 1.5px, transparent 1.5px);
  background-size: 16px 16px;
}
