CSS-05 Foundation

Linear, Radial & Conic Gradients and Text Masking

Demonstrates the generation of smooth color transitions: angled linear gradients, circular radial focus gradients, 360-degree conic color wheels, and modern gradient text masking via background-clip: text.

🎯 Practical Laboratory Objective
Understand angles and color stops in gradient math functions, and leverage WebKit text masking to create vibrant headlines.

Vibrant Web Aesthetics

Achieved with background: linear-gradient(...) and -webkit-background-clip: text.

/* 1. Linear Gradient */
.linear-card {
  background: linear-gradient(135deg, #4f46e5 0%, #06b6d4 100%);
}

/* 2. Radial Gradient */
.radial-card {
  background: radial-gradient(circle, #ec4899 0%, #1e1b4b 100%);
}

/* 3. Conic Gradient */
.conic-card {
  background: conic-gradient(from 0deg, #ef4444, #10b981, #6366f1, #ef4444);
}

/* 4. Gradient Text Effect */
.gradient-headline {
  background: linear-gradient(90deg, #ec4899, #8b5cf6, #3b82f6);
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
}
