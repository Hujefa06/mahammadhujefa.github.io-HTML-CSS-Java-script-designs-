3D Transformations and Interactive Card Flip

Demonstrates spatial 3D rendering in CSS: defining focal perspective distance, preserve-3d hierarchy, rotateY(180deg) axis turns, and backface-visibility: hidden to prevent backwards rendering.

🎯 Practical Laboratory Objective
Understand how perspective determines the visual vanishing point for 3D elements and how dual-faced cards are implemented purely in CSS.

/* Perspective Viewing Parent */
.scene-container {
  perspective: 1000px;
}

/* 3D Rotating Inner Card */
.card-3d {
  transform-style: preserve-3d;
  transition: transform 0.8s ease;
}
.card-3d.flipped {
  transform: rotateY(180deg);
}

/* Front and Back Surfaces */
.card-face {
  backface-visibility: hidden; /* Hides back of surface */
}
.card-back {
  transform: rotateY(180deg);
}
