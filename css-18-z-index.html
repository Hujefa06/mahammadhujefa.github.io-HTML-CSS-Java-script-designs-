CSS-18 Layout

z-index Layering and Stacking Contexts

Demonstrates the vertical 3D depth axis (Z-axis) of CSS rendering: positioned elements with positive/negative z-index numbers and how isolation / transform / opacity establish distinct stacking contexts.

🎯 Practical Laboratory Objective
Understand why z-index only works on positioned elements (relative, absolute, fixed, sticky) and why a child cannot poke through a parent's stacking context boundary.
