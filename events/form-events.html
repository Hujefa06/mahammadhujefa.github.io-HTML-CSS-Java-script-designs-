Form Events Lifecycle (focus, blur, change, input, submit)

Observe the real-time event pipeline of HTML forms: focus (gaining cursor), blur (losing focus), input (keystroke mutations), change (committing changes), and submit (form dispatch).

Event Dispatch Log:

readyForm loaded
const input = document.getElementById("fieldName");
const select = document.getElementById("fieldBranch");
const form = document.getElementById("sampleForm");

// 1. Focus & Blur
input.addEventListener("focus", () => console.log("Field focused"));
input.addEventListener("blur", () => console.log("Field lost focus"));

// 2. Real-time Input
input.addEventListener("input", (e) => console.log("Value:", e.target.value));

// 3. Committed Value Change
select.addEventListener("change", (e) => console.log("Branch changed:", e.target.value));

// 4. Submit Event with preventDefault
form.addEventListener("submit", (e) => {
  e.preventDefault(); // Prevents page reload
  console.log("Form submitted successfully!");
});
