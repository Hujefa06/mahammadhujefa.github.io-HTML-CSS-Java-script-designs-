Event Propagation: Bubbling vs Capturing

Visualize how events flow through nested DOM hierarchies across 3 phases: Capturing (trickling down), Target, and Bubbling (rising up), and how event.stopPropagation() terminates the chain.

const child = document.getElementById("child");
const parent = document.getElementById("parent");
const grandparent = document.getElementById("grandparent");

// 1. Bubbling Phase (Default: 3rd parameter is false)
child.addEventListener("click", (e) => {
  console.log("Child (Bubbling)");
  // e.stopPropagation(); // Halts bubbling upwards
}, false);

parent.addEventListener("click", () => {
  console.log("Parent (Bubbling)");
}, false);

grandparent.addEventListener("click", () => {
  console.log("Grandparent (Bubbling)");
}, false);

// 2. Capturing Phase (3rd parameter is true: { capture: true })
grandparent.addEventListener("click", () => {
  console.log("Grandparent (Capturing)");
}, true);
