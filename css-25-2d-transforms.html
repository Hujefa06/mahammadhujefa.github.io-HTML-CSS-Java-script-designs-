CSS-25 Effects

2D Transformations: Translate, Rotate, Scale & Skew

Demonstrates matrix coordinate manipulations in 2D space without distorting surrounding document geometry: translate(X, Y), rotate(deg), scale(ratio), and skewX/Y angle tilting.

🎯 Practical Laboratory Objective
Understand why transform operations perform on GPU composite layers, allowing silky 60fps animations without triggering costly browser CPU reflows.
⚡ Live 2D Transform Sandbox
Working Demo
2D MATRIX
transform: rotate(0deg) scale(1) translate(0px, 0px) skew(0deg); 
/* Compound 2D Transformations */
.transformed-box {
  transform: rotate(15deg) 
             scale(1.1) 
             translate(20px, -10px) 
             skewX(-5deg);
  transform-origin: center center; /* Pivot point */
  transition: transform 0.2s ease;
}
