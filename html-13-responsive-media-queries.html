HTML-13 Layout & Semantic

Responsive Webpage using CSS Media Queries

Demonstrates adaptive layout techniques using CSS3 @media at-rules. The layout seamlessly transforms from a 4-column desktop display to a 2-column tablet layout, and collapses to a single column on mobile screens.

🎯 Practical Laboratory Objective
Understand fluid grid systems, viewport meta tag configurations, and breakpoint strategies using min-width and max-width conditions to support diverse client display form factors.

/* Default Desktop: 4 Columns */
.grid-container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 16px;
}

/* Tablet Breakpoint: 2 Columns */
@media (max-width: 1024px) {
  .grid-container {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Mobile Breakpoint: 1 Column */
@media (max-width: 640px) {
  .grid-container {
    grid-template-columns: 1fr;
  }
}
