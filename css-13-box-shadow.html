CSS-13 Effects

Box Shadow Elevation and Inset Depth Effects

Demonstrates the box-shadow syntax: horizontal offset, vertical offset, blur radius, spread distance, color with alpha transparency, inset debossed styling, and smooth transition elevation lifts.

🎯 Practical Laboratory Objective
Understand how multi-layer ambient lighting shadows create tactile depth in modern interface design systems and how inset shadows convey depressed button states.

/* Syntax: box-shadow: [offset-x] [offset-y] [blur] [spread] [color] [inset?]; */

/* 1. Ambient Glow Elevation */
.card-elevation {
  box-shadow: 0 8px 20px -3px rgba(79, 70, 229, 0.2);
}

/* 2. Inset Sunken Well */
.inset-well {
  box-shadow: inset 0 3px 8px rgba(0, 0, 0, 0.15);
}

/* 3. Smooth Hover Card Lift */
.interactive-card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}
.interactive-card:hover {
  transform: translateY(-8px);
  box-shadow: 0 20px 35px -5px rgba(79, 70, 229, 0.3);
}
